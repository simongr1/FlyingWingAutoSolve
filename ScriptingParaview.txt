Scripting Paraview:

freecad starts paraview with a script --script pvScript.py

that script can do any paraview command - including loading a state for analysis

from paraview.simple import *
LoadState("/home/eprice/src/FlyingWing/A0AAnalysis.pvsm",".")

and then do things with the output for example save it:

SaveData("/tmp/mycsv.csv",proxy=FindSource("PlotDataOverTime1"))

see also https://docs.paraview.org/en/latest/Tutorials/SelfDirectedTutorial/batchPythonScripting.html#creating-a-pipeline

other useful ones:

CP=inputs[1].GetPoints()
F=inputs[1].PointData['F'][0]
M=inputs[1].PointData['M'][0]
U=inputs[0].PointData['U'][0]


#U=numpy.array((-1,-1,0)) #debug
mass_density=1.2 
u2=numpy.linalg.norm(U)**2
q=0.5*mass_density*u2

D0=-U/numpy.linalg.norm(U)
S00=numpy.array((0,1,0))
L0=numpy.cross(D0,S00)
L0=L0/numpy.linalg.norm(L0)
S0=numpy.cross(L0,D0)

L1=numpy.dot(L0,F)
D1=numpy.dot(D0,F)
S1=numpy.dot(S0,F)
output.PointData.append(numpy.array((D1,S1,L1)),'AF')
output.PointData.append(F,'F')
output.PointData.append(numpy.array((M[0],-M[1],-M[2])),'M')

cL=L1/q
cD=-D1/q
output.PointData.append(cL,'cL')
output.PointData.append(cD,'cD')
